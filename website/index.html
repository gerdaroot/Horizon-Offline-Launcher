Install

One command. No sign-in.

What changes from the official launcher

The game is the same Horizon. Only the launcher is different.

1

No account needed

Play starts the game offline under your own name. Add a Microsoft account only if you want online-mode servers with your licensed name and skin.

2

Choose your own jar

Point “Choose jar…” at a 26.3.jar from TLauncher, Downloads or a USB stick. Otherwise the launcher searches Prism, MultiMC, Modrinth, ATLauncher and GDLauncher for it.

3

It never updates itself

An upstream update can’t bring the account requirement back. You update by running the install command again.

4

One-command install

Desktop and Start menu shortcuts are created for you. No administrator rights needed on Windows.

Everything else works as in Horizon: mods, resource packs, instances, servers, and playing with friends by invite code.

First run

Four steps, and the first three only happen once.

  1. 1

    Have Minecraft 26.3. If you don’t, download and start version 26.3 once in any launcher: official, TLauncher, Prism and others.

  2. 2

    Open Horizon Offline Launcher. It downloads the latest Horizon by itself.

  3. 3

    Press “Prepare” on the Resources row. The launcher finds your 26.3.jar and builds textures and sounds from it, in a few minutes. If it can’t find the jar, press “Choose jar…”. It usually sits in .minecraft\versions\26.3\.

  4. 4

    Press “Play”. Change your offline name with the player button at the top right.

Questions

Quick answers before you install.

Will a jar from another version, like 1.21, work?

No. Horizon reproduces 26.3 exactly, and its data and network protocol are tied to that version. The launcher checks the file’s checksum and tells you when the jar is the wrong one.

Preparing asks for Java.

Preparing needs Java 25. The launcher looks for it in other launchers and downloads it if it finds none. If that fails, install Java 25 and try again.

How do I play with friends?

Open Pause, then Friends, to get an invite code. LAN works too. Online-mode servers need a Microsoft account, added in Settings, then Accounts.

Where are my worlds?

Where the official Horizon launcher keeps them. Both launchers use the same data folder, so worlds, instances and settings are shared.

How do I update?

Run the install command again. It puts the latest release over the old one, and your worlds and settings stay.

Windows says “Windows protected your PC”.

The file isn’t code-signed. Click “More info”, then “Run anyway”.

Can I build it from source?

Yes. Clone the repository. On Windows run build.ps1; on Linux and macOS run cargo build --release inside the launcher folder.
